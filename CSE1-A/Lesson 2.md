## Introduction to Cloud Service Models
- Definition:
	- These are frameworks that __define how cloud services are delivered and consumed__.
	- These models __dictate how much control you have over the computing resources__ and __what responsibilities lie with the service provider versus the customer__.
- Three main cloud service models:
	- Infrastructure as a Service
	- Platform as a Service
	- Software as a Service
## Types of Cloud Service Models
### Infrastructure as a Service (_IaaS_)
- Definition:
	- _IaaS_ provides the __fundamental building blocks for cloud Information Technology__ (_IT_).
	- It offers __virtualized computing resources over the internet__, such as _virtual machines_, _storage_, and _networks_.
	> The enterprises don’t need to build and secure their own IT infrastructure — they fully power the development process with third-party servers and cloud backup storage.
- Examples:
	- Amazon Web Services
	- Microsoft Azure
### Platform as a Service (_PaaS_)
- Definition:
	- _PaaS_ provides a __platform that developers to build, deploy, and manage applications__ __without worring about the underlying infrastructure__.
	- It __includes tools, libraries, and frameworks__ needed for development.
	> In PaaS, users are billed only for the platforms that they use for the time when the services were used. There is no need to pay for excessive functionality, like in desktop solutions.
- Examples:
	- AWS Elastic Beanstalk
	- apache Stratus
### Software as a Service (_SaaS_)
- Definition:
	- _SaaS_ delivers __fully functional software applications over the internet on a subscription basis__.
	- Users access these applications via a web browser __without worrying about the installation, maintenance, or updates__.
	> SaaS provides users access to cloud computing on a subscription basis. Instead of purchasing the solution one time, as if it would be a product, the software is delivered continuously — like a service.
- Example:
	- Google Workspace (formerly G Suite)
	- Microsoft 365
### Function as a Service (_FaaS_)
- Definition:
	- _FaaS_ is a __serverless way to execute modular pieces of code__ on the edge.
	- It __lets developers write and update a piece of code on the fly__, which can then __can be executed in response to an event__, such as a user clicking on an element in a web application.
	- THis makes it __easy to scale code and is a cost-efficient way to implement microservices__.
	> In FaaS, you don’t need to deploy the whole application in the cloud. Instead, you can deploy a part of it.
- Example:
	- AWS Lambda
	- Google Cloud Functions
	- Microsoft Azure Functions
	- Cloudflare Workers
	- IBM Cloud Functions
### Identity as a Service (IDaaS)
- Definition:
	- _IDaaS_ is a type of _SaaS_.
	- It is a __cloud-based solution that provides identity and access management (_IAM_) services__.
	- It __allows organizations to manage and authenticate user identities, control access to applications and resources, and ensure secure user experiences__ across multiple platforms.
	> An identity service’s goal is to verify users are who they say they are. If the identity checks out, the solution grants them in-time access company resources.
- Example:
	- Amazon Cognito
	- Auth0 by Okta
## Importance of Understanding the Cloud Computing
- Strategic Decisions
	- Organizations must understand these models to make informed decisions about:
		- __Where to invest?__
		- __How to manage resources?__
		- __What kind of cloud solutions best meet their needs?__
- Cost Efficiency
	- Understanding the distinctions between _IaaS_, _PaaS_, and _SaaS_ __helps businesses optimize their costs__ by choosing the most appropriate model __for their specific use cases__.
- Scalability and Flexibility
	- Knowledge of these models __enables businesses to scale their operations smoothly and flexibly__, adapting quickly to changing demands __without overcommitting resources__.
